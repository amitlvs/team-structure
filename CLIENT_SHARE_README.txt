CLIENT SHARING PACKAGE

Open team.html in a browser to view the responsive organisation structure.

What is included:

- The page includes indicative delivery timelines for landing pages, small applications, and large applications.

Keep all files in this folder when sharing. The workbook download button depends on team_skill_matrix.xlsx being beside team.html.
